## Pilot protocol

Recruit consenting adult teachers, tutors or mentors through a separate authorized action. Explain that replies/feedback are authored, free text is not semantically assessed and the workflow does not certify competence. Avoid identifiable student work. Agree on access and deletion before collecting data; use a separate session directory.

Ask each participant to complete a case, explain what feedback means, reopen the saved session, try a different case and export a reflection. Observe completion, confusion, relevance, error recovery and changes in the next intended teaching move. Participants may stop at any time.

Use a separately reviewed unseen scenario for follow-up. Independent educators should assess actions/reasons without knowing who used Agent Teacher, recording valid alternatives and disagreements. Simulator scores, software tests and a small usability pilot cannot establish learning gains.
