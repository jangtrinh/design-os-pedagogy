# Cognitive Load Theory (CLT) & Human Cognitive Architecture

![Cognitive Load Theory & Working Memory Architecture](../../assets/cognitive_load_slots_1789438844913.jpg)

## 1. Biological Cognitive Architecture
* **Working Memory (WM)**: Strictly bounded in bandwidth (processing $4 \pm 1$ novel informational chunks concurrently) and transient in duration (< 20 seconds without active rehearsal).
* **Long-Term Memory (LTM)**: Effectively limitless capacity, organized into hierarchical **Cognitive Schemas**. When a complex construct is compiled into a schema, working memory treats the entire schema as a single discrete chunk.

## 2. The Three Dimensions of Cognitive Load
1. **Intrinsic Cognitive Load**:
   * The inherent difficulty of the content, governed by *element interactivity* (the number of elements that must be processed simultaneously).
   * *Pedagogical Strategy*: Segmentation, isolated-elements-first sequencing, and schema automation.
2. **Extraneous Cognitive Load**:
   * Friction introduced by deficient instructional design (cluttered slides, split-attention text/diagram separation, verbose digressions).
   * *Pedagogical Strategy*: Total elimination of decorative clutter; applying the *Dual Coding Principle* (integrating synchronized visual and auditory channels).
3. **Germane Cognitive Load**:
   * Cognitive resources dedicated to schema construction and consolidation into long-term memory.
   * *Pedagogical Strategy*: Maximized via deliberate practice, faded worked examples, and self-explanation prompts.

## 3. The Expertise Reversal Effect (Kalyuga, 2007)
* **The fundamental law of instructional calibration**:
  * **For Novices**: Fully guided instruction and **Worked Examples** yield maximum learning efficiency. Forcing novices into unassisted discovery triggers working memory overload and reinforces misconceptions.
  * **For Experts**: Once rich schemas are established, reading redundant step-by-step guidance transforms into *Extraneous Load*, depressing motivation. Experts learn optimally through open-ended, problem-based, and inquiry challenges.
