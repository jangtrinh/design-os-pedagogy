# Evidence Comparisons and Extraction Limits

The previous universal ranking mixed distinct interventions, populations and
metrics, including normalized learning gain and standardized mean differences.
Those ranks, automatic month conversions and unsourced threshold claims have
been removed. This is an authored comparison worksheet, not a new meta-analysis.

## Source-led starting points

| Question | Source note | Extraction boundary |
| :--- | :--- | :--- |
| Classroom retrieval practice | [[evidence-agarwal-2021-retrieval]] | Review context and outcome variation before generalizing |
| Worked examples in mathematics | [[evidence-barbieri-2023-worked-examples]] | Inspect comparator and moderators; do not predict effects by life stage |
| Feedback | [[evidence-wisniewski-2020-feedback]] | A pooled effect is not a prediction for one feedback message |
| Spacing | [[evidence-mawson-2025-spacing]] | Bibliography corrected; quantitative extraction remains unreviewed |

## Comparison record

For each proposed comparison, record a canonical source ID and claim ID, metric,
population, comparator, outcome, timepoint, exact URL and section or table locator.
Include uncertainty and methodological limitations. Keep Cohen's d, Hedges' g,
normalized gain and relative change distinct. Report missing values as missing.

A large positive effect is not a higher evidence grade. A rigorous null or harmful
result may have strong evidence. Neither institutional prestige nor a structural
validation pass establishes causality or local applicability.

## Operational use

Start with the learner's task and prior knowledge, then inspect evidence relevant
to that context. Explain the reason for an intervention and what further
observation could change it. Keep multiple reasonable teaching approaches
available. Never sum effect sizes, translate them automatically into months,
or select methods by a universal numerical cutoff.

## Review boundary

Legacy claims remain unreviewed in the registry. Bibliographic correction and
abstract extraction are narrower than methodological appraisal. Authored examples
and simulation outcomes are not classroom effectiveness evidence. Use independent
performance and transfer observations to investigate local learning outcomes.
