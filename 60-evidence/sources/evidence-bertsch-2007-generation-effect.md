# Generating versus reading: meta-analytic abstract

**Extracted from the abstract:** the generation effect is defined as better memory
for information that participants produce themselves (for example synonyms) than
for material they only read. The review pooled 445 effect sizes from 86 studies and
examined 11 potential moderators. The abstract reports an overall effect size of
.40, which it describes as almost half a standard deviation in favour of
generation over reading, and states that variability due to moderator type was
substantial.

**Scope read:** abstract only. The abstract does not state the metric definition,
participant ages or the task types behind each moderator, so this record does not
support a claim about any specific classroom population or about summary writing.

**Applicability limit:** most generation tasks in this literature are short verbal
items. Using the finding to motivate learner-built summaries or tables is a design
inference (authored), not a tested transfer of this estimate.
